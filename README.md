UNICHILD INTERNATIONAL SCHOOL — Website Project
📌 Project Overview
The UNICHILD INTERNATIONAL SCHOOL Website is a group web development project designed to create a professional, responsive, and user-friendly online platform for UNICHILD INTERNATIONAL SCHOOL, Agenda Roman Hill.
The website will provide students, parents, prospective students, staff, and visitors with important information about the school.
🎯 Objectives
Create a professional online presence for the school.
Provide accurate school information.
Showcase academics, activities, events, and facilities.
Provide admission and contact information.
Ensure the website works on phones, tablets, and computers.
Develop a maintainable and reliable website.

Requirements → Planning → UI/UX Design → Frontend → Backend → Content → Testing → Client Review → Deployment
🔀 GitHub Workflow
The team will use GitHub for collaboration, task management, version control, and code review.
Developers will work on feature branches, create Pull Requests, and merge approved work into the development branch before the final version goes to main.
