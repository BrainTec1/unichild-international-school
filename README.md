## 📖 About the Project

Brain International School (BIS) is a private basic school located at Amasaman, near the Police Station, in the Greater Accra Region of Ghana. The school offers education from **Nursery** through **Junior High School (JHS 3)**.

This repository contains the complete **School Management System** — a centralized web platform combining:

- 🌐 A **public website** for parents and visitors
- 🔐 A **private management portal** for administrators, teachers, parents, and students
- 💰 **Fee tracking** with offline payment recording and receipt generation
- 📊 **Attendance, results, and report card** management
- 📰 **Content management** for news, events, and gallery

The system is designed to operate as a **single digital school office** — one source of truth for student, academic, and financial records.

---

## 🎯 Project Goals

- **Consolidate** all school operations into one platform
- **Secure** role-based access to sensitive student information
- **Simplify** fee tracking without requiring online payments
- **Empower** parents with real-time visibility into their children's progress
- **Support** teachers with easy attendance and score entry
- **Preserve** complete audit trails of all administrative actions
- **Last** at least 5 years with minimal maintenance
- **Be maintainable** by any developer with JavaScript experience

## 🏗️ Tech Stack

| Layer | Technology | Why |
|-------|-----------|-----|
| **Runtime** | Node.js 20+ | Modern, fast, JavaScript everywhere |
| **Backend** | Express 4 | Minimal, well-understood framework |
| **Templating** | EJS | Server-side HTML rendering |
| **Database** | MySQL 8 | Reliable, widely supported |
| **ORM** | Prisma | Type-safe database access |
| **Authentication** | express-session + bcryptjs | Simple, secure session auth |
| **PDF Generation** | PDFKit *(planned)* | Report cards and receipts |
| **Styling** | Tailwind CSS | Utility-first, consistent design |
| **Frontend JS** | Vanilla JavaScript + Alpine.js *(planned)* | Progressive enhancement |
| **Deployment** | VPS (Hostinger / Contabo / DigitalOcean) | Full control, low cost |
